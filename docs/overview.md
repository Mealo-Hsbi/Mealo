# Project Overview

**Mealo** is a comprehensive meal planning and management application. It combines a robust Node.js backend with a modern Flutter frontend to deliver a seamless experience for users looking to organize their meals, discover new recipes, and manage their dietary preferences.

## Purpose
- Simplify meal planning for individuals and families
- Provide personalized meal recommendations
- Enable ingredient and nutrition tracking
- Support healthy eating habits

## Main Features
- User authentication and profiles
- Meal plan creation and management
- Recipe discovery and search
- Ingredient recognition via image upload
- Nutrition analysis
- Favorites and history tracking

## Target Audience
- End-users seeking to improve their meal planning
- Developers interested in fullstack app architecture
- Contributors looking to enhance an open-source project

## Automated Testing
Mealo uses automated tests for both the backend (Node.js) and frontend (Flutter) to ensure code quality and reliability. See [Testing & Quality Assurance](tests.md) for details on how tests are structured, run, and extended.
