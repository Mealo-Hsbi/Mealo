# Contributing Guide

Thank you for your interest in contributing to Mealo!

## How to Contribute
1. Fork the repository
2. Create a new branch (`feature/your-feature` or `bugfix/your-bug`)
3. Make your changes
4. Write tests for new features or bug fixes
5. Commit and push your changes
6. Open a Pull Request (PR) with a clear description

## Code Style
- Follow the existing code style for JavaScript (backend) and Dart (frontend)
- Use meaningful variable and function names
- Write clear, concise comments where necessary

## Branching
- `main`: Production-ready code
- `feature/*`: New features
- `bugfix/*`: Bug fixes

## Pull Requests
- Ensure your branch is up to date with `main`
- Provide a detailed description of your changes
- Reference related issues if applicable

## Reporting Issues
- Use GitHub Issues to report bugs or request features
- Provide steps to reproduce, expected behavior, and screenshots if possible
