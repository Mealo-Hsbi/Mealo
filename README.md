# Mealo

## Quick Start

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
flutter pub get
flutter run
```

For detailed setup instructions, see [Setup & Installation](docs/setup.md).

## About
Mealo helps users plan meals, manage ingredients, and discover recipes. It features user authentication, image recognition, personalized meal plans, and more.
